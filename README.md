Название проекта: Логическая игра с интерфейсом «Быки и коровы» (Bulls and Cows)
Python
Описание:

Разработал классическую консольную игру на угадывание чисел с реализацией алгоритма случайной генерации секретного кода и валидацией пользовательского ввода.

Что было сделано:

- Реализовал алгоритм генерации уникального 4-значного числа без повторяющихся цифр.
- Написал логику посимвольного сравнения строк для подсчета «быков» (точных совпадений) и «коров» (совпадений без учета позиции).
- Реализовал обработку исключений и валидацию ввода (проверка на длину строки, дубликаты и некорректные символы).
- Оптимизировал код, разбив логику на независимые функции/методы для улучшения читаемости.
